# Burnly

Burnly is a local desktop app for tracking AI coding-tool token usage.

## Development

Install dependencies:

```bash
pnpm install
```

Run the frontend dev server:

```bash
pnpm dev
```

Run the desktop app:

```bash
pnpm tauri dev
```

Run the local verification gate:

```bash
pnpm verify
```

Use `pnpm verify:fast` while iterating.
